# kellermannak.github.io

GitHub Pages site of the **algorithmic techno generator**: endless, hard, pounding techno,
generated and synthesized from a seed. No samples, no vocals.

- Live preview: https://kellermannak.github.io (rendered songs of the current engine version)
- Code and docs: [`techno/`](techno/README.md)

The site is built by [`.github/workflows/pages.yml`](.github/workflows/pages.yml) on every
push to `main`.
